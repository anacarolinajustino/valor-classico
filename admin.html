Exportar base

O banco guarda só o estado atual da coleta: quando um anúncio muda de preço, o valor anterior é sobrescrito. Baixe um arquivo depois de cada coleta e guarde os arquivos juntos — como toda linha traz a coluna data_extracao, basta empilhá-los para ter a série histórica. CSV no padrão brasileiro (separador ; e vírgula decimal), abre no Excel com duplo clique.

O resumo traz uma linha por marca/modelo/versão/geração/ano com quantidade, média, mediana e faixa de preço — é o formato direto para a série. Os anúncios trazem a base inteira, um anúncio por linha, para quando você quiser recalcular algo diferente depois.
